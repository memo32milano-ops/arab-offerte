# بوت قناة "عروض إيطاليا بالعربي"

بوت بينشر عروض أمازون إيطاليا في قناة تليجرام بلينك العمولة بتاعك.
بيشتغل ببلاش على GitHub Actions كل حوالي 10 دقايق، ومش محتاج سيرفر.

## بتستخدمه إزاي (من الموبايل)
1. في تطبيق أمازون، افتح المنتج ← مشاركة ← اختار البوت بتاعك في تليجرام.
2. ممكن تكتب تحت اللينك (اختياري):
   ```
   https://amzn.eu/d/xxxx
   شنيور بوش 18 فولت
   59.99 99.90
   ```
   السطر التاني هو العنوان بالعربي، والتالت هو السعر الجديد والقديم.
3. البوت بيحط العرض في الطابور، وبينشره في القناة في وقت مناسب (من 8 الصبح لـ 11 بالليل)، وبيسيب بين كل عرض والتاني ساعة ونص.
   لو الطابور فيه أكتر من 8 عروض بيسرّع لكل 40 دقيقة.

أوامر البوت: `/queue` و`/now` و`/del 2` و`/clear` و`/help`

## الإعداد (مرة واحدة بس)
1. **البوت:** في تليجرام افتح @BotFather ← `/newbot` ← اختار اسم ← انسخ التوكن.
2. **القناة:** اعمل قناة Public، وضيف البوت فيها **أدمن** بصلاحية النشر.
3. **أمازون:** سجّل في programma-affiliazione.amazon.it، وضيف لينك القناة كمكان للترويج، وخد الـ tag بتاعك (شكله زي `xxxxx-21`).
4. **GitHub:** في الريبو ← Settings ← Secrets and variables ← Actions، ضيف:
   - Secret اسمه `BOT_TOKEN`: توكن البوت
   - Variable اسمه `AMAZON_TAG`: الـ tag بتاع أمازون (في تبويب Variables)
   - القناة متحددة جوه ملف الـ workflow: `@ArabOfferteItalia`
5. ابعت `/start` للبوت. أول واحد يبعت بيتسجل أدمن، وده انت.

## ملاحظات
- البوت مش بيسحب بيانات من موقع أمازون، لأن ده ممنوع في شروطهم. هو بس بيحوّل اللينك اللي انت بتبعته.
- لما يبقى عندك مبيعات كفاية، أمازون بيفتح لك **Creators API**، وساعتها نضيف وضع أوتوماتيك كامل يدوّر على الخصومات لوحده.
- البوت بيعمل commit يومي لملف `state.json`، عشان GitHub ميوقفش الجدولة.
